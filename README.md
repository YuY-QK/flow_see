# 动画流（flow_see）

把任何有流程的事物或原理，做成可以观察、可以交互的动画，让它们更容易被理解。

## 项目目标

世界上有大量“按步骤发生”的事物：算法如何一步步执行、网络协议如何握手、
工作流程如何流转、科学原理如何演化。纯文字和静态图很难表达“过程”本身。

**动画流**希望做到：

- 把流程类内容（算法、协议、工作流程、科学原理等）可视化为动画
- 支持观察与控制：播放、暂停、单步、回退、调速
- 让人一眼看清“每一步发生了什么、状态如何变化、为什么”
- 新增一个动画的成本尽量低，便于持续扩充内容

## 当前状态

第一个里程碑（M1：跑通核心）已完成：可以在网页上用「消息传递」模板新建动画、编辑步骤、实时预览、带字幕和朗读播放，作品自动保存在本地浏览器。

## 本地运行

需要 Node.js 20+ 和 pnpm。

```bash
pnpm install
pnpm dev        # 启动开发服务器，默认 http://localhost:5173
pnpm test       # 运行单元测试
pnpm lint       # 代码检查
pnpm build      # 类型检查并打包
```

## 目录结构

```
src/
├── engine/      # 纯 TypeScript：作品数据结构、编辑、播放状态机、主题
├── templates/   # 动画模板（每个模板一个文件夹）及注册表
├── player/      # 播放器
├── editor/      # 编辑器组件
├── pages/       # 页面
├── services/    # 本地存储、朗读
├── store/       # 编辑器状态
├── ui/          # 通用界面组件
└── styles/      # 全局样式与设计变量
```
