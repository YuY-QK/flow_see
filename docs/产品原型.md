# 动画流 · 产品原型（第 1 版）

> 状态：待确认。确认后作为第一版开发的依据。
> 讨论过程见 [原型讨论记录](./原型讨论记录.md)；可点击原型图：https://claude.ai/artifact/6HVVPun7G2KW82adbtteir

## 1. 产品定位

**一句话**：把任何有流程的事物或原理（算法、协议、工作流程、科学原理等），通过填表单 + 选模板，做成可以观察、可以操控的讲解动画。

**目标用户**：小孩子、学生/自学者、老师/讲解者，以及“我自己”。

**核心体验**：默认带讲解自动播放（字幕 + 朗读），随时可以停下来单步、回退、跳转、改参数自己摸索。

**形态**：网页 + App，电脑和手机都要好用。

## 2. 第一版范围

### 做

| 模块 | 内容 |
|---|---|
| 创建 | 选模板 → 填步骤表单（默认简单，可展开高级参数）→ 实时预览 → 自动保存 |
| 动画模板 | 可配置、易扩展的模板体系；内置 4 类：流程图流转、消息传递、数据变化、循环/时间线 |
| 动画主题 | 专业风、简洁扁平、卡通可爱、手绘黑板 |
| 播放器 | 播放/暂停、上一步/下一步、进度条、调速、步骤目录、字幕、语音朗读、全屏、改参数重播、高级参数 |
| 动画广场 | 只放官方制作 + 精选；按主题、按动画类型筛选，可搜索；可“复制并修改” |
| 我的作品 | 保存在本设备；草稿 / 已分享；编辑、分享、导出、复制、删除 |
| 分享 | 上传到服务器，生成短链接；打开即可观看和操作 |
| 导出 | 视频 / GIF |
| 设置 | 默认动画主题、界面语言、大字号、朗读（开关/声音/语速）、默认播放速度、备份导出/导入 |

### 不做（后续版本）

- **AI 生成动画**（输入一句话生成）
- **账号体系**：架构上预留，后续接入要轻松；网页端可以做账号，App 端先不做
- **用户投稿 / 社区**：后续做在网页端（避开 App 审核）；作品署名是作品自带的作者名，与账号无关，以后可再关联账号；社区热度高的作品可选入精选并署名作者

### 全局导航

- **电脑**：顶部导航栏。左侧 Logo +「首页 / 动画广场 / 我的作品」；右侧搜索框、设置、「+ 创建动画」。

## 4. 各页面模块

### 4.1 首页
1. 一行弱化的产品介绍：“把流程变成看得懂的动画”
2. 创建入口：“今天想讲清楚什么？”+ 四个模板快捷入口
3. 继续编辑：最近的草稿
4. 推荐动画 + “去动画广场找更多灵感”

### 4.2 动画广场
1. 标题、说明、搜索
2. 主题分类：全部、算法、网络协议、自然科学、人体与生命、生活流程、工作流程
3. 动画类型筛选
4. 作品卡片：缩略图、标题、主题、来源（官方 / 精选）
5. 点卡片进入播放页

### 4.3 播放页
1. 标题区：所属分类、标题、动画类型、来源；操作：分享、导出视频/GIF、复制并修改
2. 舞台：动画本体（可显示统计，如比较/交换次数）
3. 讲解字幕：第 N 步 / 共 M 步、本步标题、说明；朗读状态
4. 播放控制：上一步、播放/暂停、下一步、进度条、调速、朗读开关、全屏
5. 侧栏（手机为底部抽屉）：
   - 步骤目录：点击跳转
   - 试试改参数：修改输入（如一组数字）、选项（如排序方向）、随机一组、重新播放；高级选项

### 4.4 分享链接打开页
- 与播放页相同，但不显示站内导航
- 顶部提示栏 +「我也要做一个」按钮（进入创建流程）

### 4.5 创建 · 选模板
1. “你想讲清楚什么？”
2. 四张模板大卡片，每张带小动画示例和适用场景
3. “从一个示例改起”：官方示例快捷入口 + 去广场找灵感

### 4.6 创建 · 编辑器
- **顶部**：返回换模板、动画名称、自动保存状态、外观、导出、分享
- **左侧（编辑）**：
  - 模板标识
  - 参与者 / 元素（随模板变化，如“消息传递”是角色）
  - 步骤卡片列表：未选中只显示标题和说明；选中后可编辑“这一步发生了什么”“一句话解释”；可拖动排序、删除
  - 「更多设置」展开高级参数（随模板变化；如消息传递：谁发出、发给谁、箭头标签、停留时长、朗读内容）
  - 「+ 添加一步」
- **右侧（预览）**：实时预览 + 字幕 + 播放控制
- **外观面板**：动画主题、自动朗读、朗读声音、观众是否可以改参数
- **手机**：底部「编辑 / 预览」切换

### 4.7 我的作品
1. 提示：作品保存在本设备；分享过的会存一份到云端；备份/导入入口
2. 全部 / 草稿 / 已分享
3. 新建卡片 + 作品卡片；“⋯”菜单：编辑、分享链接、导出、复制一份、删除

### 4.8 设置
- 外观与语言：默认动画主题、界面语言（同时决定朗读语言）、大字号
- 朗读与播放：自动朗读、朗读声音（可试听）、朗读语速、默认播放速度
- 数据与备份：导出备份、导入

## 5. 关键交互规则

1. **两种观看模式无缝切换**：默认自动播放并朗读；任何手动操作（单步、拖进度、点目录）都自动暂停。
2. **步骤是一切的核心**：每个动画是一串步骤；播放、跳转、目录、字幕、朗读、导出都基于同一份步骤数据。
3. **模板决定表单和画面**：每个模板定义自己的“元素”、步骤字段、高级参数和画法；新增模板不影响其他部分。
4. **改参数重播**：支持参数的模板（如数据变化），观众改输入后重新生成步骤并从头播放；作者可在外观里关闭。
5. **作品默认本地保存**，自动保存不丢稿；分享时才上传服务器得到短链接。
6. **复制并修改**：任何广场作品或别人分享的作品，都能复制成自己的草稿再改。

## 6. 视觉规范

- **界面风格**：清爽明亮。浅灰白底（#F6F7FB）、白色卡片、大圆角（卡片 16–24px）、细边框、少阴影。
- **主色**：蓝 #2F5FE0。
- **模板识别色**（底色 / 文字色）：
  - 流程图流转：#EAF0FF / #2F5FE0
  - 消息传递：#FFF1E5 / #9A4700
  - 数据变化：#E6F6EE / #1E7F4F
  - 循环/时间线：#F0ECFF / #5A3FC4
- **文字**：主文字 #1F2433，次要文字 #5B6275；系统中文字体。
- **可用性**：点击区域不小于 44px；文字对比度符合无障碍要求；提供大字号选项。
- **动画主题**只影响动画画面，不影响界面本身。
