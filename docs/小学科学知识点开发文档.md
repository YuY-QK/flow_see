## 0. 先说三件要你确认的事

数学的知识点清单是你给的；科学的清单是我拟的，所以和数学文档不同，这里有三处需要你确认后才算定稿：

| # | 事项 | 我的建议 | 影响 |
|---|---|---|---|
| 1 | **教材版本** | 按**教科版**（2017 年起使用的版本）的单元排。依据：现有 4 个科学知识点的单元名（水、植物的生长变化、太阳地球和月球、电路）和四年级目录文件里写的“教科版”一致 | 单元名称和年级位置。换版本只改课程目录，知识点本身基本通用 |
| 2 | **做多少** | 科学不做“全部知识点”，只做**适合用动画讲的**：过程、变化、看不见的原理（共 104 个，见第 3 节）。观察、种植、饲养、制作这类必须动手的活动不做 | 工作量。教科版 1–6 年级共 44 个单元，本清单每单元选 1–4 个 |
| 3 | **已上线的 4 个不动** | `water-states`、`plant-life`、`shadow-change`、`simple-circuit` 保持原样，包括它们所在的年级和单元 id。其中“植物的生长变化”在 2017 版教科版里是四年级下册，现有目录放在三年级，不移动 | 无 |

如果你用的是别的版本（人教鄂教版、苏教版、青岛版等），告诉我版本，我按那个版本重排第 3 节的单元；知识点内容大部分可以保留。

## 2. 总体规划

### 2.1 知识点怎么选

| 规则 | 说明 |
|---|---|
| 只做动画讲得更好的 | 过程（发芽、消化、水循环）、变化（月相、四季、物态）、看不见的原理（电流、磁力、声波、粒子）、需要多角度看的结构（地球内部、花） |
| 不做必须亲手做的 | 观察记录、种植饲养、搭建制作、测量练习。这些在讲解里用一句话带过，鼓励孩子课后去做 |
| 一个知识点一个结论 | 科学结论要准确、可检验；讲“看到了什么 → 说明什么”，不替孩子省略证据 |
| 每个知识点至少一处动手做 | 以点选（指出器官、选出条件）、分类（导体绝缘体、沉浮）、转动（调时间看月相、调杠杆支点）为主 |
| 低年级少而浅 | 一、二年级每单元 1–2 个，以认识和比较为主；三年级起每单元 2–4 个 |

### 5.2 知识点文件

- 位置：`packages/content/lessons/science/g<年级>/<id>.yaml`。
- 知识点 id 全站唯一，本清单的 id 已和数学的 206 个 id 核对过，没有重名。

### 5.3 素材

科学比数学更依赖素材，尤其是 `diagram` 的底图。原则同数学文档 5.6，另加两条：

- **结构类底图必须准确**（器官的位置和形状、花的结构、细胞）。AI 绘制的要对照权威图谱逐项检查，这是自校清单“科学性”一条的重点。
- 底图画成“干净的示意图”（不带文字、不带引线），文字和引线由 `diagram` 零件画，这样换主题、换语言都不用重画。

### 5.5 科学正确性要点（补充数学文档 8.3）

| 领域 | 要点 |
|---|---|
| 物质 | 溶解后物质还在（质量不变），不是“消失”；蒸发在任何温度下都发生，沸腾才需要到沸点；热传递的是能量，不是“热的颗粒”跑过去；空气有质量、占据空间；物理变化和化学变化的区别是有没有产生新物质 |
| 生命 | 植物自己制造养料（光合作用需要光），不是“从土里吃养料”；种子发芽不需要光（需要水、空气、适宜的温度）；食物链箭头指向捕食者（表示能量流动方向）；呼吸交换的是氧气和二氧化碳，呼出的气体里仍有氧气；遗传和变异不要讲成“血型、智力一定遗传” |
| 地球与宇宙 | 四季的原因是地轴倾斜，**不是**离太阳远近；月相的原因是日、地、月的相对位置，**不是**地球的影子（影子造成的是月食）；地球自西向东转，所以太阳东升西落；月球本身不发光；日食只发生在农历初一前后，月食在十五前后 |
| 运动与力 | 力是改变物体运动的原因，不是维持运动的原因；摩擦力方向和运动方向相反；摆的快慢只和摆长有关；定滑轮不省力、动滑轮省力但不改变方向；杠杆省力就费距离；物体的浮沉取决于同体积下和水相比的轻重，不是单看重量或大小 |
| 光、声、电、磁 | 光在同一种均匀物质里沿直线传播；反射角等于入射角；声音传播需要介质；音高由振动快慢决定、音量由幅度决定；电路要闭合才有电流；磁铁有两个磁极，磁力不需要接触；电磁铁的磁性可以随电流有无而有无 |
