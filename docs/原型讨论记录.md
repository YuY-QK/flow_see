# 动画流 · 原型讨论记录

逐轮记录产品原型的讨论结论。全部确认后整理成正式原型文档，再开始开发。

## 第 1 轮：定位（已确认）

- **目标用户**：小孩子、我自己、学生/自学者、老师/讲解者
- **内容来源**：预制精选库、用户自己创建、AI 按描述生成都要有；
  **主要方式是表单生成**：用户逐个填写步骤，选择动画类型/风格等，系统结合表单和动画模板生成动画
- **观看体验**：两者结合，默认带讲解自动播放，随时可以停下来自己操作（暂停、单步、回退等）
- **设备与形态**：电脑和手机都要好用，网页和 App 都要支持

## 第 2 轮：创建方式与产出（已确认）

- **步骤表单**：先选模板，不同模板有各自的步骤表单；默认填写简单（标题+说明），
  并支持展开详细参数设置（角色、动作、数据等）
- **动画类型（模板）**：做成可配置、易扩展的模板体系。第一版内置四类：
  1. 流程图流转：方块+箭头，节点依次高亮，适合工作流程、判断分支
  2. 消息传递：多个角色之间来回发消息，适合网络协议、审批
  3. 数据变化：一排数字/格子变换位置，适合排序、查找等算法
  4. 循环/时间线：按时间或圈状推进，适合水循环、生命周期、历史事件
- **AI**：第一版不做 AI 生成（保留为后续方向）
- **产出去向**：全部支持
  - 分享链接（打开即可观看、可交互）
  - 导出视频 / GIF
  - 公开到「动画广场」（他人可浏览、收藏、一键复制修改）
  - 保存到自己的作品列表

## 第 3 轮：观看体验、主题与账号（已确认）

- **播放器功能**：全部要
  - 基础控制：播放/暂停、上一步/下一步、进度条拖动、调速
  - 步骤目录：列出全部步骤，点击跳转
  - 语音朗读：自动朗读每步说明
  - 改参数重播：观看时修改输入（如换一组数字），立即重新播放
  - 更高级的参数设定（具体项待细化）
- **儿童适配**：不做独立儿童模式；界面统一、简单易懂，通过可选的多种主题（含可爱/卡通风）适配不同人群
- **账号**：第一版不做账号体系，但架构上要预留，后续接入要很轻松
- **动画广场**：只放官方制作 + 管理员精选的作品

### 连带说明

- 没有账号时，用户作品存在本地（浏览器/设备）；分享链接需要能脱离账号工作
- 第一版广场只有官方 + 精选内容；用户投稿放到后续版本（见第 5 轮）

## 第 4 轮：页面结构、创建页、投稿与分享（已确认，部分待定）

- **首页**：弱化产品介绍，重点放推荐动画和“创建”入口；动画广场作为灵感入口
- **页面清单（初稿）**：首页、动画广场、播放页、创建页、我的作品、设置（主题/语言/朗读）
- **创建页**：要求“人性化、简单易操作”，由我提出设计方案（见下）
- **投稿与社区**：
  - 用户以“投稿”方式发布，**不匿名**，要显示作者
  - 社区做在**网页端**（避开 App 商店审核）
  - 社区里热度高的作品，可以被选入「精选」，并署上作者名
- **分享链接**：服务器存储，生成短链接（需要一个简单后端，也为后续账号、投稿打基础）

### 创建页设计提案（待确认）

采用“向导起步 + 实时预览编辑器”：

1. 第一步只问一件事：“你想讲清楚什么？”，用大卡片选模板，每张卡片带一个小动画示例
2. 进入编辑器：步骤以卡片列表呈现，每张卡片默认只有“标题 + 一句说明”，点“更多设置”才展开详细参数
3. 预览常驻：电脑上左边编辑、右边实时预览；手机上用底部“编辑 / 预览”切换
4. 风格、主题、速度等放在顶部一个“外观”按钮里，不打断填写
5. 随时自动保存到本地，不会丢稿；提供“从示例开始”，直接拿官方动画改

## 第 5 轮：署名、账号范围与风格（已确认）

- **署名与账号无关**：署名只表示“这个作品是谁做的、来自社区”，是作品自带的作者名，不依赖账号；
  以后有账号时可以再把作品和账号关联
- **账号范围**：网页端可以做账号，App 端先不做
- **投稿/社区**：不着急，**不放第一版**，后续再加
- **界面风格**：清爽明亮（白底、大圆角、柔和彩色点缀，友好不幼稚）
- **动画主题（第一版）**：专业风、简洁扁平、卡通可爱、手绘黑板
- **创建页**：先画可点击的原型图，看过再定
