# 动画学堂 · 小学版需求设计

> 依据：[教学平台方案](./教学平台方案.md) 第 0 节。状态：待确认（第 2 版：按反馈改了顶部栏和侧边栏，新增个人中心、设置）。
> 产品名称：**动画学堂**。第一次进入默认显示**一年级**。
> 产品原型（电脑 / iPad / 手机，可点击）：https://claude.ai/artifact/4yBmxqu535rGPaeS36iDpW
> 逐页需求规格（页面流程图、全局与业务规则、每页的状态/跳转/验收标准）：[小学版页面规格](./小学版页面规格.md)。两份文档有出入时以页面规格为准。

## 1. 目标与范围

**目标**：把小学数学、科学的重点和难点知识点做成可以看、可以动手调的动画，让孩子看懂“为什么”。

**第一版范围**

| 做 | 不做（以后再说） |
|---|---|
| 网页版，适配电脑、iPad、手机 | App |
| 小学 1–6 年级的数学、科学 | 语文、英语等其他学科；初中及以上 |
| 学习中心：年级 → 学科 → 单元 → 知识点 → 动画 | 账号、云端学习记录 |
| 知识点动画：讲解、朗读、单步、拖进度、**动手试一试**（点选换例子、滑块等） | 练习题、测验、错题本（见[需求池](./需求池.md)） |
| 本机记录“最近学过”“已学完” | 排行榜、积分、社交（见[需求池](./需求池.md)） |
| 创作（保留现有表单创作）、分享链接、导出视频/GIF | 用户投稿、评论 |
| **内容全部由配置文件驱动** | 内容管理后台（先用文件 + 校验工具） |

## 2. 用户与场景

| 用户 | 场景 |
|---|---|
| 孩子（6–12 岁） | 在 iPad 或电脑上找到这周学的知识点，看动画、拖滑块自己试 |
| 家长 | 孩子问“为什么”时，打开对应知识点一起看；把链接发到家长群 |
| 内容作者（你本人） | 写配置文件新增知识点，本地预览、校验，推送后自动上线 |

## 4. 各页面功能需求

### 4.0 顶部栏与侧边栏（所有页面共用）

**顶部栏**

| 位置 | 内容 | 规则 |
|---|---|---|
| 左 | 头像 | 点击打开侧边栏 |
| 头像右侧 | 模块名或层级路径 | 一级页面显示模块名（学习、创作、个人中心、设置）；下级页面显示路径，如“学习 › 一年级 › 数学 › 凑十法”，前面每一级都能点击返回 |
| 右 | 搜索 | 平时是图标；点击后原地展开输入框并自动聚焦；点击别处（输入框失去焦点）收起为图标 |
| 右 | 年级下拉 | 点击弹出一到六年级；只在学习相关页面出现 |
| 右 | 学科下拉 | 点击弹出数学、科学（带学科色）；只在学科页和学习页出现 |

- 首页只显示年级下拉（首页同时展示两个学科）；创作、个人中心、设置不显示年级和学科。
- 在学习页切换年级或学科，跳到对应的年级·学科页。
- 下拉面板打开时，点击面板以外的地方关闭。

**手机上的差异**

- 层级路径改为两行：上面一行小字是上级路径（可点击返回），下面一行是当前页名。
- 年级和学科合并成一个按钮（如“一年级·数学 ▾”），点开后在同一个面板里选。
- 搜索展开时铺满整个顶部栏，右侧有“取消”。

**侧边栏**

- 从左侧滑出，点遮罩或关闭按钮收起。
- 顶部：Logo + “动画学堂”。
- 个人信息卡：头像、昵称、年级、已学完数量，点击进入个人中心。
- 菜单：学习、创作、学习记录、设置（注明“主题、语言、朗读”）、帮助与反馈；当前所在模块高亮。
- 底部提示：学习记录和作品保存在这台设备上。


### 4.1 学习中心（首页）

- 顶部：问候语（带昵称）和当前年级说明。年级在顶部栏的年级下拉里切换；默认用上次的选择，第一次进入默认一年级。
- 学科卡片：数学、科学。显示本年级已上线的知识点数，以及本机记录的已学完数量。
- 继续学习：本机最近学过的 3–4 个知识点，点击回到上次的进度。
- 本年级推荐：配置里标了推荐的知识点。
- 某年级某学科还没有内容时，显示“即将上线”，不显示空白。

### 4.2 年级·学科页

- 页面顶部是学科横幅：“一年级 · 数学”，以及单元数、知识点数、已学完数。年级和学科在顶部栏切换。
- 按单元分组；单元下是知识点卡片，卡片上有缩略图、名称、一句话简介、时长、状态。
- 状态：已学完（本机记录）、未学、即将上线（配置了但还没发布）。

### 4.3 知识点学习页

- **舞台**：动画画面。支持连续动画（钟表转动、影子移动）和步骤动画。
- **字幕与朗读**：每一步一句讲解，默认朗读。低年级字号更大。
- **控制**：播放/暂停、上一步/下一步、拖动进度条逐帧查看、调速、朗读开关、全屏。
- **动手试一试**：配置里声明的控件（滑块、按钮组、开关）。拖动后画面立即变化；可以“回到标准讲解”。
- **要点小结**：2–4 条要点，配置提供。
- **学完标记**：播放到最后一步，或手动点“我学会了”，在本机标为已学完。
- 上一个 / 下一个知识点（按单元顺序）；分享链接；导出视频/GIF。

### 4.4 创作

沿用现有功能，入口在侧边栏。页面包含新建动画、我的作品、从模板开始。

### 4.5 个人中心

- 学习统计：已学完、学过的知识点数，学习天数（只统计本机）。

- 提示：资料只保存在本机，以后有账号可以登录同步。

## 5. 配置驱动设计（核心）

### 5.1 原则

**新增一个知识点，只需要加配置文件和素材，不改代码。**

能不能“不改代码”，取决于这个知识点用到的**画面零件**是否已经有了：

| 情况 | 需要做什么 | 是否改代码 |
|---|---|---|
| 用现有模板（如钟表、分数、竖式），改参数和讲解 | 写一个知识点配置文件 | **不改** |
| 现有零件能拼出来，但没有现成模板 | 用“场景模板”在配置里摆零件、写每一步的动作 | **不改** |
| 需要一种全新的零件或交互（比如以后的 3D） | 新增一个零件或模板 | 改（一次性，之后所有知识点都能用） |

目标是让绝大多数小学知识点落在前两种情况。

### 5.2 配置文件一览

```
packages/content/
├── site.yaml                  # 站点公共配置：名称、联系方式、各项默认值、条数上限等（见页面规格 2.7）
├── help.yaml                  # 常见问题
├── texts.yaml                 # 界面文案（按钮、提示、标题）：分组 → 键 → 文字，代码里用 t('分组.键') 读取
├── style.yaml                 # 动画主题（配色、圆角、字体）和导出视频/GIF 的画面样式
├── examples/                  # 创作页的示例动画：index.yaml（分类、顺序）+ 每个示例一个文件
├── curriculum/
│   ├── grades.yaml            # 年级、学科、学科配色
│   └── math/grade3.yaml       # 某年级某学科的单元与知识点目录
├── lessons/
│   └── math/g3/fraction-intro.yaml   # 一个知识点一个文件
├── assets/
│   ├── manifest.yaml          # 素材清单：来源、作者、许可证
│   └── science/plant/*.svg
└── schemas/                   # 由代码自动生成的 JSON Schema，编辑器里有补全和报错
```

- 格式用 **YAML**：手写友好，能写注释，中文不用转义。
- 每种配置都有 **JSON Schema**，编辑器能自动补全、实时报错。
- `pnpm content:check` 检查全部配置：格式、引用的模板/素材/知识点是否存在、讲解词长度、必填项。推送前和自动部署时都会跑。
- 本地 `pnpm dev` 时，改配置文件，浏览器里的动画立即刷新。

### 5.4 知识点配置（用现有模板）

```yaml
# lessons/math/g3/fraction-intro.yaml
id: fraction-intro
title: 认识分数
summary: 把一个整体平均分，取其中的几份
status: published            # draft / reviewed / published
reviewedAt: 2026-11-10
duration: 2分钟
tags: [分数, 平均分]
recommended: true

template: fraction           # 用哪个模板
params:                       # 模板的参数（标准讲解时的取值）
  shape: circle
  parts: 4
  take: 3

explore:                      # 动手试一试：哪些参数开放给孩子调
  - param: parts
    control: slider
    label: 平均分成几份
    min: 2
    max: 12
  - param: take
    control: slider
    label: 取其中几份
    min: 1
    max: "{parts}"            # 可以引用其他参数

steps:                        # 讲解步骤：每步一句话，可选动作
  - say: 这是一个完整的饼。
    show: whole
  - say: 把它平均分成 {parts} 份，每一份都一样大。
    show: split
  - say: 取其中的 1 份，就是它的 {parts} 分之一，写作 1/{parts}。
    show: take-one
  - say: 取其中的 {take} 份，就是 {parts} 分之 {take}，写作 {take}/{parts}。
    show: take-many

keyPoints:
  - 一定要“平均分”，每一份同样大，才能用分数表示
  - 分母表示平均分成几份，分子表示取了几份
```

- 讲解词里的 `{parts}` 会随孩子调的参数自动变化（“平均分成 6 份”）。
- `derived` 写由参数算出来的值：`derived: { gap: 10 - a, rest: b - gap }`。算式支持四则运算、括号、`min`/`max`/`floor`/`ceil`/`round`/`abs`；后面的可以用前面的。
- `presets` 写点选的例子：`presets: [{ label: 8 + 6, params: { a: 8, b: 6 } }]`。
- `explore` 的 `min`/`max` 可以写式子（`min: 11 - a`）。
- 完整例子：`lessons/math/g1/make-ten.yaml`（凑十法，可换成 8 + 6 等）。
- 缩略图：知识点配置的可选字段 `cover`，用这个知识点自己的动画画面做缩略图（滚到可见时才加载），不用另外做图：`cover: { step: 4, params: { hour: 3 }, text: '3:00' }`——`step` 用第几步的画面（默认最后一步），`params` 用什么参数（默认标准取值），`text` 是画面加载出来之前显示的文字（如算式“9 + 4”“3/4”，没写就显示名称的第一个字）。
- 动手做：在某一步加 `try`，这一步在“跟着做”“自己做”时由孩子来做（规格 P3）。`do` 仍然写标准做法（看一看时播放、“看我做一遍”、做对后的画面都用它）：

```yaml
- title: 凑成 10
  say: 把这 {gap} 个放进十格框，{a} 和 {gap} 凑成 10。
  do:
    - move: { target: one, to: left }
  try:
    task: 把 {gap} 个橙色圆片拖进十格框。          # 轮到孩子时显示并朗读
    drag: { from: one, to: left, count: '{gap}' }   # 从 one 拖 gap 个到 left
    hints: [要放进左边的十格框里哦。, 看，放到亮起来的十格框里。]   # 做错时依次给出
```

  `content:check` 会检查：`from`、`to` 在这一步开头存在，`from` 是计数块且个数够，`do` 里有对应的拆分/移动且个数和 `count` 一样；每种参数组合都查。动手方式：拖动（`drag`，只有场景模板）、点选答案（`choose`，所有模板）；转动把手随后加。点选的写法见 `lessons/scene.md`。
- `show` 是模板约定好的几种画面状态，每个模板在文档里列出可用的值。

### 5.5 知识点配置（用场景模板，不写代码）

没有现成模板时，用 `scene` 模板：先摆好零件，再写每一步对零件做什么。

```yaml
id: make-ten
title: 凑十法：9 + 4
template: scene
stage: { width: 800, height: 450 }

objects:                       # 舞台上的零件
  - id: left
    type: counters             # 零件类型：计数块
    count: 9
    at: [120, 200]
    layout: tenframe           # 十格框排列
  - id: right
    type: counters
    count: 4
    at: [520, 200]
    color: orange
  - id: formula
    type: text
    text: "9 + 4 = ?"
    at: [400, 380]
    size: 40

steps:
  - say: 9 加 4，我们先看 9 还差几个凑成 10。
    do:
      - highlight: left
  - say: 9 还差 1 个就是 10，从 4 里拿出 1 个。
    do:
      - split: { target: right, take: 1, as: one }
      - move: { target: one, to: left, duration: 1s }
  - say: 现在是 10 加 3，等于 13。
    do:
      - set: { target: formula, text: "10 + 3 = 13" }
      - highlight: formula
```

**零件（第一批）**：文字、数字、算式、分数、计数块（小棒/方块/圆片，可按十格框或点阵排列）、数轴、钟面、分数圆/分数条、方格、几何图形（长方形、三角形、圆、扇形）、线段与箭头、标注框、图片素材；阶段 2 又加了：拆分算式图（split-calc）、竖式（column-calc）、切圆拼图（circle-cut）、粒子示意（particles）、光与影（sun-shadow）、电池 / 灯泡 / 开关 / 导线（battery、bulb、switch、wire），计数块的“盘子”（点阵写 capacity）。

**动作（第一批）**：出现、隐藏、高亮、移动、拆分、合并、改文字或数值、旋转、缩放、颜色变化、数字递增，以及按时间连续变化（如指针转动）。动作可以设置时长，同一步里的多个动作可以同时进行或依次进行。

零件和动作的完整写法（属性、参数、默认时长）见 [packages/content/lessons/scene.md](../packages/content/lessons/scene.md)。

### 5.8 新增一个知识点的完整流程

1. 准备素材（开源或 AI 绘制），放进 `assets/`，在 `manifest.yaml` 里登记来源。
2. 新建 `lessons/学科/年级/xxx.yaml`，写参数、步骤、讲解、要点。
3. 在课程目录里加上这个知识点的 id。
4. `pnpm dev` 本地预览，按自校清单检查，把 `status` 改成 `published`。
5. `pnpm content:check` 通过后推送到 GitHub，Cloudflare 自动构建上线。

整个过程不碰代码。

### 5.9 哪些仍然需要写代码

- 新的零件类型（比如以后要做电路的“电流流动”效果）。
- 新的模板（比如需要复杂计算生成步骤的竖式乘法）。
- 新的交互方式（比如拖拽拼图）。

这些都是**一次性**的：做好之后，所有知识点都能通过配置使用。

## 6. 第一版的模板与零件

| 模板 | 用于 | 主要参数 |
|---|---|---|
| `scene` 场景 | 大多数知识点（凑十法、平均分、植物的一生……） | 零件 + 每步动作 |
| `clock` 钟表 | 认识钟表、时间计算 | 起止时间、显示刻度/数字 |
| `fraction` 分数 | 认识分数、分数比较、同分母加减 | 形状、份数、取几份 |
| `column-calc` 竖式 | 加减乘除竖式 | 两个数、运算 |
| `area-grid` 面积 | 长方形/正方形面积、割补 | 长、宽、单位 |
| `shadow` 光与影 | 影子的变化 | 时间、物体高度 |
| 现有四个 | 流程图、消息传递、循环/时间线、数据变化 | 不变 |

后三个模板（竖式、面积、光与影）如果用场景模板能讲清楚，就不单独做模板。

## 7. 本机学习记录

- 保存在浏览器本地：最近学过（知识点 + 进度）、已学完、选择的年级。
- 不需要账号；换设备不同步（以后接账号时再迁移）。
- 设置页可以清除学习记录。

## 8. 非功能需求

| 方面 | 要求 |
|---|---|
| 设备与尺寸 | 电脑（≥1024 宽）、iPad（768–1023，横竖屏）、手机（<768）三档布局 |
| 浏览器 | Chrome、Edge、Safari（含 iPad）、手机自带浏览器、**微信内置浏览器**（家长常从微信打开链接） |
| 触控 | 点击区域不小于 44px；滑块在 iPad 上手指好拖 |
| 性能 | 首页首屏只加载目录索引；知识点内容按需加载；中低端平板播放流畅 |
| 可读性 | 低年级字幕字号更大；颜色对比度达标；朗读可关闭 |
| 部署 | 推送到 GitHub 后 Cloudflare 自动构建；分享接口用 Cloudflare Pages Functions + KV；保留 Node 部署方式 |
| 隐私 | 不收集个人信息；学习记录只在本机 |
