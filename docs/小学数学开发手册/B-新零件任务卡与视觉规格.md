# B · 新零件任务卡与视觉规格

> 先读 [README](./README.md) 第 3 节（完成标准）和第 4 节（通用视觉规范）。
> 所有零件都依赖 A 文件的 **F6（子项与把手接口）** 和 **F7（零件文字约定）**；用到数组插值的依赖 **F1**；列表随参数变化的依赖 **F5**；含分数 / 上标文字的依赖 **F4**。卡上只写额外依赖。

## 0. 每张零件卡的通用做法

**改动文件（每个零件都一样）**

| 文件 | 内容 |
|---|---|
| `packages/blocks/src/parts/<文件>.tsx` | `PartDef`：`type`、`name`（中文名，零件名属于“面向写配置的人的报错”例外，可以写中文）、`anchor`、`required`、`props`、`normalize`、`bbox`、`subitems`、`handles`（有把手时）、`Render`。布局计算写成导出的纯函数 `<零件>Layout(p)`，`bbox`、`subitems`、`Render` 都调用它 |
| `packages/blocks/src/parts/<文件>.test.ts` | 卡上“测试”列出的全部用例 |
| `packages/blocks/src/index.ts` | 注册零件，导出布局函数 |
| `packages/content/site.yaml` | `scene.parts.<type>`：卡上“属性”表里的默认值，带注释 |
| `packages/templates/src/scene/check.ts` | 卡上“检查”列出的零件特有检查 |
| `packages/content/lessons/scene.md` | 零件表加一行（属性、`at` 含义、连续属性、子项名、例子） |
| 样板知识点 | `packages/content/lessons/math/g<年级>/<id>.yaml`，`status: draft`，id 用卡上“样板知识点”写的那个（正是 C 文件里第一个用到它的知识点），内容取 C 脚本的前 2–3 步即可；之后写正式知识点时在它上面补全 |

**分支**：`dev/phase3-block-<type>`。**完成标准**：README 第 3 节 + 零件试验场（F9）里四个主题截图 + 卡上测试全过。

**属性表的“默认”**：写进 `site.yaml`；“—”表示必填或没有默认。

## B1 `item-set` 物品组　（批次 3.1，估时 1.5 天）

**用途**：一组各不相同的物品（水果、文具、小动物、图形），用于点数、序数、分类、比较、连加连减。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `items` | 列表 | — | 每项：`asset`（素材 id）或 `shape`（circle / square / triangle / star），可选 `color`、`size`（覆盖整体大小）、`tags`（对象，sort 用）、`value`（数值，tap 条件和凑数用）、`label`（物品下方小字） |
| `layout` | row / grid / pile | row | row 一排；grid 按 `cols` 换行；pile 随意堆放（位置由序号算出的固定散点，见下） |
| `cols` | 整数 | 5 | grid 每行几个 |
| `size` | 数 | 56 | 每个物品的格子大小（正方形） |
| `gap` | 数 | 12 | 格子间距 |
| `color` | 颜色 | blue | shape 物品的默认颜色 |
| `show` | 数（可连续） | 物品总数 | 只画前几个（见“连续变化”） |
| `hiddenItems` | 序号列表 | [] | 隐藏的物品 |

- **锚点**：`at` 是左上角（`anchor: start`）。
- **画法**：第 n 个（从 1 开始）格子左上角 = `at + ((n−1) % cols × (size+gap), floor((n−1)/cols) × (size+gap))`（row 时 cols = 物品数）。素材图片按格子大小等比放入、居中；shape 用格子的 80% 画，填充 + 描边（README 4.2）。`label` 写在格子下方 8 像素处，字号 20，ink。pile 的散点：第 n 个的偏移 = `(sin(n × 2.4) × size × 0.35, cos(n × 1.7) × size × 0.25)`，叠加在 grid（cols = ceil(√数量)）的位置上——固定可复现。
- **连续变化**：`items` 是对象列表，不插值（F1）。数量变化用两个数值属性：`show`（数，可连续，默认 = 物品总数）：只画前 `show` 个，小数部分是第 `ceil(show)` 个的淡入 / 淡出进度——上车、拿走从末尾增减都用它；`hiddenItems`（序号列表，立即生效）：隐藏中间某几个。
- **子项**：`<n>`（box = 第 n 个格子，`value` = 该项 value，`tags` = 该项 tags）。
- **检查**：`items` 展开后为空报错；`asset` 必须在素材清单里。
- **测试**：row / grid / pile 下第 1、6、12 个的位置；`show` 3.5 时画 4 个且第 4 个半透明；`hiddenItems` 后被隐藏的不画、子项仍存在但不可点；包围盒包含 label。
- **样板知识点**：`count-to-10`（一年级）。

## B2 `number-bond` 分合图　（3.1，1 天）

**用途**：数的组成（“7 可以分成 3 和 4”）、想加算减、一图四式。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `whole` | 数 | — | 整体 |
| `parts` | [数, 数] | — | 两个部分 |
| `dir` | down / up | down | down：整体在上、两部分在下（分）；up：两部分在上、整体在下（合） |
| `show` | 0–2 | 2 | 0 只有整体；1 画出两条分叉线；2 写出两部分（连续：线从整体往下长出；数字淡入） |
| `size` | 数 | 44 | 数字字号 |
| `blank` | 子项名列表 | [] | 要孩子答的，画成闪烁空框 |
| `colors` | `{ whole, p, q }` | `{ whole: ink, p: blue, q: orange }` | 各数字颜色，可写 `@id` |

- **锚点**：`at` 是整体数字的中心。
- **画法**：每个数字放在圆角框里（框宽 = max(文字宽, size) + size × 0.5，高 = size × 1.4，圆角 8，line 色描边 2，白色 / 主题背景填充）。两部分的中心 = 整体中心 + (∓size × 1.6, ±size × 2.2)（down 时 y 为正）。分叉线从整体框底边中点到两部分框顶边中点，线宽 3，line 色。
- **子项**：`whole`、`p`、`q`（各自框的 box）。
- **测试**：dir down / up 的位置；show = 1.5 时数字半透明；blank [q] 时 q 画空框。
- **样板知识点**：`compose-10`。

## B3 `base-ten` 十进制块　（3.1，2.5 天）

**用途**：小棒和捆、方块和条 / 片 / 大正方体；讲计数单位、进位（满十捆成一捆）、退位（拆开一捆）。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `style` | stick / block | stick | stick 小棒（个是一根、十是一捆）；block 方块（个是小方块、十是条、百是片、千是大正方体） |
| `ones`、`tens`、`hundreds`、`thousands` | 数（可连续） | 0 | 各单位的个数 |
| `columns` | 布尔 | true | true 按数位分列（从右到左：个、十、百、千），false 混在一起从左往右按大到小排 |
| `labels` | 列表 | `[个, 十, 百, 千]` | 列下的文字（`columns: true` 时写；`site.yaml` 默认，F7） |
| `unit` | 数 | 16 | 一根小棒的宽 / 一个小方块的边长 |
| `color` | 颜色 | blue | 主色 |

- **锚点**：`at` 是整体左上角。
- **画法（stick）**：一根小棒 = 宽 unit × 0.5、高 unit × 6 的圆角竖条（橙黄色木棒感：用 `color` 填充 + 描边），小棒之间间距 unit × 0.4；一捆 = 10 根紧挨着并在中部画一条横向“绳子”（accent 色，线宽 3），捆与捆间距 unit × 1。
- **画法（block）**：小方块 = unit × unit；条 = 1 × 10 个小方块竖排（画出格线）；片 = 10 × 10（画格线，线宽 1）；大正方体 = 斜二测的立方体（正面 10 × 10 格，顶面和右侧面按 `scene.solid.obliqueAngle`、`depthRatio` 画），每一级之间间距 unit。
- **列**：`columns: true` 时每一列宽 = 该列最多需要的宽度（按当前个数算），列间距 unit × 2，列下方 unit 处写 `labels`（字号 22，dim）。个数多时在列内换行（小棒每行最多 10 根 / 10 捆；方块每行最多 10 个 / 5 条 / 3 片）。
- **连续变化（捆与拆）**：`ones` 和 `tens` 同时变化时，零件根据“前后差”画过程：从 `ones: 13, tens: 2` 到 `ones: 3, tens: 3` 的中间状态 e（用插值后的小数部分推算：`moving = 10 × frac`），画面是 10 根小棒从个位列向十位列飞去，前 50% 并拢、后 50% 移动并出现绳子。实现方法：`normalize` 不变；`Render` 读取插值中的非整数值，`k = ones` 的小数部分决定过程。**约定**：知识点里捆 / 拆一次只改一个十（`ones ±10`、`tens ∓1`），多次捆用 `repeat`。check：一次 `set` 里 `ones` 变化量不是 0 或 ±10 时报警告。
- **子项**：`ones`、`tens`、`hundreds`、`thousands`（各列 box）；`tens.<n>`（第 n 捆）、`ones.<n>`（第 n 根）。
- **测试**：13 根 = 1 捆 + 3 根的位置；中间状态 e = 0.25、0.75 画面元素数量；block 千位的立方体包围盒；`columns: false` 排列。
- **样板知识点**：`count-to-100`。

## B4 `place-value` 计数器 / 数位表　（3.1，2 天）

**用途**：读数写数、数的组成、大数分级、小数数位、小数点移动。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `value` | 数（可连续） | 0 | 当前数（整数或小数） |
| `places` | 整数 | 2 | 最高位（0 个位、1 十位…8 亿位） |
| `decimals` | 整数 | 0 | 小数位数 |
| `style` | abacus / chart | abacus | abacus 计数器（竖杆串珠）；chart 数位表（表格写数字） |
| `groups` | 布尔 | false | true 时在数位上方标出“个级、万级、亿级”并用粗线分隔 |
| `showDigits` | 布尔 | true | abacus 时杆下方是否写出这一位的数字 |
| `blank` | 子项名列表 | [] | |
| `labels` | 对象 | `{ places: [个位, 十位, 百位, 千位, 万位, 十万位, 百万位, 千万位, 亿位], decimals: [十分位, 百分位, 千分位], groups: [个级, 万级, 亿级], point: 小数点 }` | F7，`site.yaml` 默认 |
| `color` | 颜色 | blue | 珠子颜色（abacus 每一位交替用 color 和 orange，便于区分） |

- **锚点**：`at` 是整体中心。
- **画法（abacus）**：底座长方形（line 色描边，高 24）；每一位一根竖杆（高 260，线宽 4，dim），杆间距 70；珠子是扁圆（宽 44、高 20），从底座往上叠，一根杆最多 9 颗（第 10 颗出现时触发进位过程，见下）。杆下方写位名（字号 20，dim），`showDigits` 时在位名上方写数字（字号 32，ink）。小数点：在个位和十分位之间的底座上画一个实心圆点（半径 6）。
- **画法（chart）**：一行表头（位名，字号 20）+ 一行数字（字号 36）的表格，单元格宽 70、高 50；`groups` 时表头上方再一行级名，跨对应的 4 列。
- **连续变化**：`value` 从 a 到 b 时，按位逐个变化：每一位的珠子数取插值后数值在该位的数字（`digit(round(value × 10^decimals), k)`），视觉上珠子一颗颗增减（新珠子从杆顶落下 0.2 的过程用小数部分推算）。进位（个位 9→10）：个位 10 颗珠子并拢、淡出，十位落下 1 颗——由 `value` 跨过 10 的整数倍时的小数部分驱动。
- **子项**：`d<k>`（第 k 位那一列的 box，个位 `d0`，十分位 `d-1`）；`point`。tap 某一位的语义（“拨一颗珠子”）由知识点的 `tap` + `do` 表达，零件只提供子项。
- **检查**：`value` 的位数超过 `places` 报错；小数位超过 `decimals` 报错。
- **测试**：value 305 时三根杆珠子数 3、0、5；value 1.25、decimals 2 的小数点位置；groups 时级名跨列；9→10 中间状态。
- **样板知识点**：`place-value-100`。

## B5 `number-chart` 百数表　（3.1，1.5 天）

**用途**：数序、找规律、倍数特征、质数筛。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `from`、`to` | 整数 | 1、100 | |
| `cols` | 整数 | 10 | |
| `cell` | 数 | 38 | 格子边长 |
| `marks` | 列表 | [] | 每组 `{ multiplesOf, color, style: circle / fill / cross, keepSelf }`；`keepSelf: true` 时这个数本身不标（质数筛：2 留着，2 的其他倍数划掉） |
| `reveal` | 数（可连续） | 0 | 0 到组数：整数部分 = 已完全出现的组数；小数部分 = 当前组按从小到大出现的比例 |
| `size` | 数 | 18 | 数字字号 |

- **锚点**：左上角。
- **画法**：格子线 line 色线宽 1；数字居中 ink。标记：fill 用该色 0.35 不透明度填满格子；circle 在数字外画圆（半径 = cell × 0.38，线宽 3）；cross 在格子里画斜线（从左下到右上，线宽 3，该色）。同一格多组标记叠加（fill 在下，circle 和 cross 在上）。
- **子项**：`n.<数>`（value = 这个数）、`row.<n>`、`col.<n>`。
- **测试**：`n.37` 的 box；reveal 1.5 时第二组只出现一半（按数从小到大）；keepSelf。
- **样板知识点**：`order-compare-100`。

## B6 `expr-steps` 递等式　（3.1，2 天）

**用途**：四则混合运算的运算顺序、简便运算、连加连减。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `expr` | 文字 | — | 算式（运算符 `+ − × ÷ ( ) [ ]`），零件按运算顺序自动生成每一行；和 `lines` 二者写一个 |
| `lines` | 文字列表 | — | 手写每一行（第 2 行起自动在行首加“=”）；简便运算用 |
| `show` | 数（可连续） | 1 | 写出几行（小数部分 = 下一行淡入进度） |
| `underline` | 布尔 | true | 在每行“这一步先算的部分”下画线（accent，线宽 3），下一行对应的结果写在线的正下方 |
| `notes` | 文字列表 | [] | 每一行右侧的说明（字号 22，dim），如“乘法分配律” |
| `size` | 数 | 36 | |

- **锚点**：第一行左端的中心（`anchor: start`，at 是第一行文字基线左端）。
- **自动生成规则（expr）**：每一行只算**一步**：找当前最内层括号里的第一个乘除（没有就第一个加减）；没有括号时找第一个乘除，没有就第一个加减。中括号视为外层括号。算完一步写成下一行，括号里只剩一个数时去掉括号。行与行间距 size × 1.5，从第二行起行首“=”与第一行的第一个字左对齐、其余文字右移一个“= ”的宽度（教材格式：等号对齐）。
- **子项**：`line.<n>`；`op.<n>`（第一行第 n 个运算符号及其两边的数的范围）。
- **检查**：`expr` 解析失败报错；结果不是有限数报错。
- **测试**：`36 + (48 − 12) × 2` 生成 3 行：`= 36 + 36 × 2`、`= 36 + 72`、`= 108`；`[(5 + 3) × 4 − 2] ÷ 3` 的行；`lines` 自动加等号；underline 的范围。
- **样板知识点**：`continuous-add-sub`。

## B8 `money` 人民币（示意）　（3.3，1.5 天）

**用途**：认识人民币、换钱、购物、小数初步。规定见开发文档 4.3“人民币”。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `items` | 数列表 | — | 面值（单位元）：硬币 0.01、0.02、0.05、0.1、0.5、1；纸币 1、5、10、20、50、100。硬币和纸币都有 1 元：写 `1` 是硬币，写 `'1n'` 是纸币 |
| `layout` | row / grid / pile | row | 同 item-set |
| `cols` | 整数 | 5 | |
| `size` | 数 | 1 | 整体缩放 |
| `show`、`hiddenItems` | 同 item-set | | 数量变化（换钱时一张变多张：先画 1 元，再 `show` 从 0 到 10 画出 10 个 1 角） |
| `labels` | 对象 | `{ yuan: 元, jiao: 角, fen: 分, sample: 示意 }` | F7 |
| `colors` | 对象 | 见开发文档 5.3 `scene.parts.money.colors` | |

- **锚点**：左上角。
- **尺寸（size = 1）**：硬币直径：1 分 30、2 分 34、5 分 38、1 角 40、5 角 44、1 元 50。纸币宽高：1 元 120 × 60、5 元 128 × 64、10 元 136 × 68、20 元 144 × 72、50 元 152 × 76、100 元 160 × 80。
- **画法**：硬币：圆形，面值色填充，外圈一条同色加深的细圈（线宽 2，内缩 4）；中间写面值数字（字号 = 直径 × 0.42，ink 或白色——深色面值用白色，浅色用 ink，按颜色亮度自动选）和单位（字号 = 直径 × 0.22，写在数字下方）。纸币：圆角长方形（圆角 6），面值色填充 0.85，内缩 6 画一条细边框；左侧大字写面值数字（字号 = 高 × 0.45），旁边写单位（字号 = 高 × 0.22）；右侧留空白区域只画两条平行细线装饰（不画任何图案）。右下角“示意”小字（字号 12，dim，硬币写在底部）。**不画**人像、国徽、行名、花纹、冠字号、盲文、防伪标记。
- **单位换算显示**：0.1 写“1 角”，0.5 写“5 角”，0.01 写“1 分”——数字和单位按面值自动选。

| `kind` | beam / seesaw / dial | beam | beam 托盘天平；seesaw 跷跷板；dial 台秤 |
| `left`、`right` | 数（可连续） | 0 | 两边重量（dial 只用 left） |
| `leftItems`、`rightItems` | 素材 id 列表 | [] | 盘里 / 跷跷板两端放的东西（从左到右排，最多 6 个，超过时叠两层） |

| `maxTilt` | 数 | 15 | 最大倾斜角（度） |

- **锚点**：底座中心底边。

- **画法（dial）**：方形秤身 + 圆形表盘（半径 = width × 0.3）+ 顶部托盘；表盘刻度 0 到 `max`，每 `max/10` 一个数字；指针角度 = `left / max × 330°`（从 12 点方向顺时针）。
- **子项**：`left`、`right`（盘或木板端的 box）。
- **测试**：tilt 计算；left = right 时水平；dial 指针角度；包围盒包含倾斜后的最低点。

## B24 `solid` 立体图形（伪 3D）　（3.7，5 天，最复杂）

**用途**：认识立体图形，长方体正方体的特征、展开图、表面积、体积与容积，圆柱圆锥的特征、展开、切拼、体积。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `kind` | cuboid / cube / cylinder / cone / sphere | cuboid | cube 时 a = b = h |
| `a`、`b`、`h` | 数 | 4、3、2 | 长、宽（进深）、高，单位长度 |
| `r` | 数 | 2 | 圆柱 / 圆锥底面半径 |
| `unit` | 数 | 40 | 1 单位长度的像素 |
| `view` | -1–1（可连续） | 0.5 | 观察方向：斜二测的斜线方向角 = `view × obliqueAngle`（正值向右上、负值向左上）；0 时退化为正视图 |
| `faces` | 对象 | `{ front: blue, top: orange, right: green, back: blue, bottom: orange, left: green }` | 各面颜色（相对的面同色） |
| `faceLabels` | 对象 | {} | 面中心的文字（如 `{ front: 前 }` 或面积 `12 cm[2](sup)`） |
| `edgeLabels` | `{ a, b, h }` | {} | 长宽高三条棱旁的文字 |
| `hiddenEdges` | 布尔 | true | 被挡住的棱画虚线（`scene.solid.hiddenDash`） |
| `unfold` | 0–1（可连续） | 0 | 展开过程（见下） |
| `net` | 1–11 | 1 | 正方体展开图类型（11 种标准展开图，编号规则见下） |
| `water` | 0–1（可连续） | 0 | 内部装水高度比例（水 = blue 0.35，上表面是一个平行四边形 / 椭圆） |
| `sweep` | 0–1（可连续） | 1 | 圆柱 / 圆锥由平面图形旋转扫出的进度：0 时只有长方形 / 直角三角形，1 时是完整立体 |
| `cutParts` | 偶数 | 16 | 圆柱切成几份 |
| `cutT` | 0–1（可连续） | 0 | 圆柱切拼成近似长方体的进度 |
| `labels` | 对象 | `{ front: 前, back: 后, top: 上, bottom: 下, left: 左, right: 右 }` | F7 |

- **锚点**：底面前下棱的中点（立体“放在桌上”的位置）。
- **投影（cuboid / cube）**：斜二测：x 向右、y 向上、z（进深）向斜后方，进深方向向量 = `(cos θ, sin θ) × depthRatio`，θ = `view × obliqueAngle`（`scene.solid` 配置：obliqueAngle 30、depthRatio 0.5）。8 个顶点由 a、b、h 和投影算出；可见面按 θ 的正负决定（θ > 0 看见前、上、右；θ < 0 看见前、上、左）；画面顺序：先画不可见棱（虚线），再画可见面（填充 0.85 + 描边 3），再画可见棱。
- **圆柱 / 圆锥 / 球**：底面画成椭圆（长轴 = 2r × unit，短轴 = 长轴 × depthRatio × 0.8）；圆柱 = 两个椭圆 + 两条侧边（后半个底椭圆画虚线）；圆锥 = 底椭圆 + 从顶点到椭圆左右切点的两条线；球 = 圆 + 一条赤道椭圆（后半虚线）+ 左上高光（white 0.5 的小椭圆）。
- **unfold（长方体 / 正方体）**：以底面为基准，其余 5 个面绕各自与底面（或相邻面）的公共棱旋转到平面上。实现方法：在 3D 坐标里对每个面的 4 个顶点做绕棱旋转（角度 = 90° × unfold，顶面跟随后面再转 90°，即两级铰链），再投影；unfold = 1 时摄像机的 view 自动过渡到 0（俯视展开图看起来是平面），即实际使用的 θ = θ₀ × (1 − unfold)，同时进深方向改为竖直（展开图平铺在纸面上，“纸面”就是舞台平面）。展开顺序：前、后、左、右四个侧面同时，顶面最后（unfold 0.6–1 时顶面再转 90°）。
- **net（正方体）**：11 种展开图按“1-4-1 型 6 种（编号 1–6）、2-3-1 型 3 种（7–9）、2-2-2 型 1 种（10）、3-3 型 1 种（11）”编号，每种给定 6 个面在 4 × 3（或 5 × 2）网格中的位置和铰链树（哪个面连在哪个面的哪条边上）；数据写成常量表 `CUBE_NETS`（几何数据，属于绘制常量，代码注释说明来源），unfold 按铰链树逐级展开。
- **圆柱展开**：unfold 时侧面沿一条高剪开、展成长方形（长 = 2πr、宽 = h），上下两个底面翻到长方形上下两侧变成圆；过程中侧面用若干竖条近似（cutParts 条），每条逐渐从弧面位置移到平面位置。
- **cutT（圆柱切拼）**：底面像 circle-cut 一样分成 cutParts 个扇形柱体，cutT 从 0 到 1 时扇形柱一上一下交错排成近似长方体（长 ≈ πr，宽 ≈ r，高 h）；复用 `circleCutLayout()` 的二维计算，再加高度方向的投影。
- **sweep**：圆柱：长方形绕左边旋转，扫过的部分用逐渐张开的椭圆弧和半透明侧面表示；sweep = 1 时为完整圆柱。圆锥同理（直角三角形绕直角边）。
- **water**：水面高度 = h × water；可见的前侧面上画水的部分（blue 0.35），水面画成顶面形状（平行四边形 / 椭圆）。
- **子项**：`face.<面名>`（面的投影多边形的包围盒）、`edge.<1–12>`（棱，编号：底面四条 1–4（前、右、后、左），顶面四条 5–8，竖棱 9–12（前左、前右、后右、后左））、`v<1–8>`（顶点：底面前左 1 起逆时针，顶面 5–8）、`height`（圆柱圆锥的高，从顶点 / 顶面圆心到底面圆心的虚线）。
- **测试**：view 0.5 时 8 个顶点坐标；θ 正负的可见面集合；unfold 0 / 0.5 / 1 时前面四个顶点坐标；net 1–11 展开后 6 个面的网格位置（与常量表一致）并且不重叠；圆柱展开长方形的长 = 2πr × unit；cutT 1 时近似长方体的长；water 0.5 水面高度；包围盒（unfold 1 时包含整张展开图）。
- **样板知识点**：`cuboid-features`；本卡完成后**先做** `cuboid-net`、`observe-cubes` 两个知识点（开发文档第 10 节第 4 条）。

| `view` | iso / front / left / top 或 0–3（可连续） | iso | 0 = iso（斜二测立体）、1 = front、2 = left、3 = top；连续值在相邻两个之间过渡（相机绕竖轴 / 俯仰平滑转动） |
| `project` | 布尔 | false | 在立体图右侧同时画出三视图（前、左、上三个小方格图，各带标题——标题在 labels） |
| `count` | 数（可连续） | 全部 | 已放下的个数（按 cubes 顺序或 fill 顺序）；小数部分 = 下一个从上方落下的过程 |
| `color` | 颜色 | blue | 三个可见面用 color 的三种明度（顶面最亮、正面中、侧面最暗：`mixColor(color, white, 0.35)` / color / `mixColor(color, ink, 0.25)`） |
| `labels` | 对象 | `{ front: 从前面看, left: 从左面看, top: 从上面看 }` | F7 |

- **锚点**：底面前左角。
- **画法（iso）**：与 solid 相同的斜二测；按“从后往前、从下往上、从左往右”的顺序画每个小正方体的三个可见面（画家算法），被挡住的面自然被覆盖。渲染前先剔除被完全挡住的小正方体：在当前视角下，挡住它三个可见面的方向上都有相邻方块的不画（铺满 10 × 10 × 10 时只画外层约 270 个），保证 1000 个方块在手机上也流畅。
- **视图（front / left / top）**：正投影：front 看 x–z 平面，有方块的格子画方格；left 看 y–z 平面（注意左视图的左右方向：从左面看时，后面的方块在左边——按教材规定）；top 看 x–y 平面（前面的在下方）。视图方格边长 = unit × 0.6，线宽 2。
- **连续 view**：0→1（iso→front）时 θ 从 obliqueAngle 过渡到 0，进深比例从 depthRatio 过渡到 0；1→2（front→left）时绕竖轴旋转 90°（用 3D 旋转后再正投影，过程中可见面会变）；2→3 与 0→3 同理。实现：用一个统一的 3D 相机（方位角、俯仰角、是否透视=否）参数化 4 个视图，view 在两个视图之间线性插值方位角 / 俯仰角。
- **count 下落**：第 k 个方块从其位置上方 3 × unit 处落下（ease：先快后慢），落地前不画阴影。
- **子项**：`cube.<n>`（第 n 个方块在当前视图下的包围盒）、`layer.<z>`。
- **检查**：cubes 有重复坐标报错；悬空（下方没有方块且 z > 0）报警告（“观察物体”题里不允许悬空）。
- **测试**：fill [3,2,2] 共 12 个且顺序正确；fill [10,10,10] 时实际绘制的方块数 ≤ 300；某组合的三视图方格（写死期望矩阵，含左视图方向）；view 0.5 时相机参数；count 4.5 时第 5 个的高度；画家算法顺序。
- **样板知识点**：`observe-cubes`（四年级）。

## 附：F6 `Handle` 接口的补充（B12、B15 需要）

polygon 的顶点把手、protractor 的整体拖动，改的不是“一个数值”。F6 的 `Handle` 类型增加两个可选字段，**由 F6 一并实现**（A 文件 F6 已按此更新）：

```ts
interface Handle {
  // ……F6 已有字段
  /** 改数组属性时的下标（polygon 顶点） */
  index?: number;
  /** 由指针位置直接算出新的属性（返回要更新的属性集合）；有它时播放器不调用 valueAt */
  apply?(p: Props, pointer: Point): Props;
}
```

turn（T2）只用于数值把手（有 `valueAt` 的）；`apply` 型把手只在零件试验场（F9）和 place（T4）这类“直接摆放”的场景里用。
