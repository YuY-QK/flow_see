# 场景模板 scene：零件与动作

没有现成模板时，用 `template: scene`：先在 `objects` 里摆好零件，再在每一步的 `do` 里写对零件做什么。完整示例见 [math/g1/make-ten.yaml](./math/g1/make-ten.yaml)。

```yaml
template: scene
stage: { width: 800, height: 450 } # 舞台大小（坐标范围），默认 800 × 450
objects:
  - { id: left, type: counters, count: 9, layout: tenframe, at: [70, 112] }
steps:
  - say: 十格框里有 9 个，还空着 1 格。
    do:
      - highlight: left
```

- 画面只由“第几步 + 步内进度”决定：单步、拖进度条、刷新后回到某一步，看到的画面都一样。
- 每一步的动画时长 = 这一步最后一个动作结束的时间；朗读和动画同时开始，都结束后才进入下一步。
- `pnpm content:check` 会检查零件类型、属性拼写、动作写法、引用的零件是否存在，并指出行号。
- 讲解、零件、动作里都可以用 `{参数名}` 代入 `params` 和 `derived`。整个值就是 `"{a}"` 时保留数字类型，所以 `count: "{a}"`、`take: "{gap}"` 都行。
- 想让孩子换例子：把数字写成参数，用 `derived` 算出拆几个、剩几个、得数，再配 `explore` 和 `presets`（见 make-ten.yaml）。
- **舞台大小、零件默认属性、颜色名、动作默认时长、高亮样式、文字宽度估算都在 `packages/content/site.yaml` 的 `scene` 一节**，改它不用改代码；知识点里写了就用知识点的。

## 零件

零件自带的文字（方向、星期、数位名、单位、月份）放 `labels`，默认值在 `site.yaml`，知识点可以覆盖。

公共属性：`id`（必填）、`type`（必填）、`at: [x, y]`、`hidden: true`（开始时隐藏，用 `show` 让它出现）、`opacity`、`scale`、`rotate`（度）、`color`、`note`（备注，不显示）。

`at` 的含义：**计数块、十格框、方格是左上角，数轴是最左端，其他零件是中心。**

颜色：`blue` `orange` `red` `green` `purple` `yellow` `pink` `brown` `gray` `white` `black`，跟随动画主题的 `ink` `dim` `accent` `line`，或 `#RRGGBB`。

## 子项

零件里可以单独引用的部分叫做**子项**（如方格的某一行、某一列、某一个格子，图表的某一根条形）。

- **写法**：`零件id.子项名`。例如：
  - `myGrid.cell.2.3`（引用 `myGrid` 方格的第 2 行第 3 列）
  - `myGrid.row.1`（引用 `myGrid` 方格的第 1 行）
- **通配符 `*`**：支持在子项名中使用 `*` 匹配多个子项。例如：
  - `myGrid.row.*`（匹配 `myGrid` 的所有行）
  - `myGrid.cell.*`（匹配 `myGrid` 的所有格子）
- **作用**：
  - 高亮子项：在 `highlight` / `unhighlight` 动作中直接写子项名（如 `highlight: myGrid.cell.2.3`，或通配 `highlight: myGrid.row.*`），高亮框会精准框住该子项；支持 `keep: true` 跨步保留。
  - 子项变色：在 `color` 动作中直接写子项名（如 `color: { target: myGrid.row.2, to: red }`），仅改变对应子项的颜色。
  - 做错提示：在 `choose.show` 中可以写子项名（如 `show: [myGrid.row.2]`），孩子做错后高亮对应子项。
  - 动手做点选：在 `tap` 交互中，孩子可以直接点选子项。
- **各零件的子项名**：见上表及后续新零件规格。

## 动作

每个动作写成 `动作名: 参数`。参数只有目标零件时可以简写：`highlight: left`，或一次多个：`highlight: [left, left-num]`。

公共选项：`duration`（时长：`1s`、`500ms` 或秒数）、`delay`（先等一会儿）、`together: true`（和上一个动作同时开始；默认一个接一个）、`ease: linear`（匀速，适合指针转动这类连续变化；默认先快后慢；follow 动作默认匀速）。

| 动作                        | 作用                                                           | 参数                                                          | 默认时长 |
| --------------------------- | -------------------------------------------------------------- | ------------------------------------------------------------- | -------- |
| `show` / `hide`             | 出现 / 隐藏                                                    | `target`                                                      | 0.5s     |
| `highlight` / `unhighlight` | 高亮 / 取消高亮。高亮只在这一步有效，`keep: true` 时一直保留   | `target`（零件 id 或 `id.子项`，支持 `*`）、`keep`、`color`   | 0.4s     |
| `move`                      | 移动。计数块移到另一组计数块时，会飞进它的空位并合并           | `target`、`to`（`[x, y]` 或零件 id）或 `by: [dx, dy]`         | 0.8s     |
| `split`                     | 拆分：从一组计数块末尾拿出几个，成为新的一组                   | `target`、`take`（默认 1）、`as`（新一组的 id）、`offset`     | 0.5s     |
| `merge`                     | 合并：一组计数块飞进另一组                                     | `target`、`into`                                              | 0.8s     |
| `set`                       | 改文字或数值：可以改零件的任意属性，数字、坐标、颜色、数组按元素连续变化 | `target` + 要改的属性，如 `text: 10 + 3 = 13`、`time: "4:00"` | 0.6s     |
| `rotate`                    | 旋转。支持绕指定点旋转：`around: [x, y]` 或子项 `'tri1.v2'`（按动作开始时的位置取）；多边形等顶点定位零件（`rotatesPoints`）直接旋转每个顶点，不改 `rotate` | `target`、`to`（转到多少度）或 `by`、`around`（坐标或子项） | 0.8s     |
| `scale`                     | 缩放                                                           | `target`、`to`（倍数）                                        | 0.5s     |
| `color`                     | 颜色变化                                                       | `target`（零件 id 或 `id.子项`，支持 `*`）、`to`              | 0.5s     |
| `count`                     | 数字递增（文字零件的 `value`）                                 | `target`、`from`、`to`                                        | 1s       |
| `hop`                       | 数轴上跳一跳（画一条弧线，有指针时指针跟着跳）                 | `target`、`from`、`to`、`label`                               | 0.8s     |
| `wait`                      | 停一会儿                                                       | `wait: 1s`                                                    | 0.5s     |
| `flip`                      | 翻折：沿对称轴翻折                                             | `target`、`axis`（`[[x1, y1], [x2, y2]]`）                    | 0.8s     |
| `follow`                    | 沿路径移动。匀速沿折线移动，零件的 `at` 对准路径点；可同步把路径零件的 `draw` 设为进度 | `target`、`path`（坐标列表如 `[[x1, y1], [x2, y2]]` 或路径零件 id）、`draw`（可选，同步画出的路径零件 id） | 路径总长/100 × 0.6s |

按时间连续变化的例子（钟面分针走一圈）：

```yaml
- set: { target: clock, time: '4:00', duration: 6s, ease: linear }
```

绕点旋转的例子（绕顶点或指定坐标旋转）：

```yaml
# 矩形绕指定坐标转 180°
- rotate: { target: rect1, by: 180, around: [0, 100], duration: 1s }
# 三角形绕自己的第一个顶点转 90°
- rotate: { target: tri1, by: 90, around: 'tri1.v1', duration: 1s }
```

翻折动作（`flip`）说明：
- `axis: [[x1, y1], [x2, y2]]` 是两点确定的对称轴（舞台坐标）。
- 过程参数 $e \in [0, 1]$：$e = 0$ 原样，$e = 0.5$ 垂直于轴方向压扁至 0（贴在轴上），$e = 1$ 完全镜像；实现为变换矩阵：沿轴方向不变，垂直于轴方向缩放 $\cos(\pi e)$。
- 翻折结束后：多边形等顶点零件（`rotatesPoints: true`）直接更新顶点为镜像后的坐标；其他零件记录 `mirrorAxis` 状态并在画面渲染时套用变换矩阵，保证后续步骤画面正确。
- 文字零件（`text`、`label`）翻折后文字会镜像，知识点配置中不要翻折文字（配置检查会报警告）。

## 颜色强对应（数字和图形同色）

算式里的数字和图形里代表它的东西要同色，孩子一眼就能对上（如 4 × 3：4 和蓝色圆点同色，3 和红色虚线行框同色）。

```yaml
objects:
  - { id: r1, type: counters, count: 4, color: blue, at: [40, 70] }
  - { id: mul, type: text, text: '[4](@r1) × [3](red @r3) = 12', at: [600, 190] }
steps:
  - do:
      - highlight: { target: [r1, r2, r3], color: red } # 高亮框的颜色
```

| 写法                           | 含义                                                                        |
| ------------------------------ | --------------------------------------------------------------------------- |
| `[4](blue)`                    | 文字里这几个字写死成蓝色（颜色名、`#RRGGBB`、`ink`/`accent` 都行）          |
| `[4](@r1)`                     | 颜色跟着零件 r1；r1 高亮时，这几个字底下衬一块同色的底，一起亮起来          |
| `[3](red @r3)`                 | 两样都要：写死红色，并且 r3 高亮时一起亮                                    |
| 零件 `color: "@id"`            | 任意零件的颜色跟着另一个零件                                                |
| `highlight: { target, color }` | 高亮框用这个颜色（默认是主题强调色）；高亮只在这一步有效，`keep: true` 保留 |
| split-calc 的 `colors`         | 见零件表                                                                    |
| `[15](blank)`                  | 要孩子答的数：不写字，画成同宽的虚线空框并缓慢闪烁（见下一节）              |
| `[2](sup)`                     | 上标（字号 × 0.6，基线上移），如 `cm[2](sup)`、`r[2](sup)`                   |
| `[3/4](frac)` / `[1 3/4](frac)`| 行内竖排分数、带分数（上下排列带分数线，可与颜色、`@id`、`blank` 组合）      |

用 `[ ]( )` 写在 YAML 的流式写法 `{ … }` 里时，整段文字要加引号。

## 提问点（ask）与不提前给答案

有 `try` 的步骤，**画面不能已经写着答案**。`do` 里写 `- ask: true` 标出“在这里提问”：

- 跟着做、自己做：先放 `ask` 之前的动作（图形先变好），等孩子做；答对后再放 `ask` 之后的动作（文字、数字、得数出现）。
- 看一看、看我做一遍：`ask` 不起作用，整段连着放。
- 不写 `ask` 时，等孩子答的时候这一步的动作一个都不放（画面停在这一步开头）。
- 分数模板（fraction）、钟表模板（clock）有 `try` 的步骤已经自动这样做：图形、钟面先摆好，文字、分数、时间答完再出。

```yaml
- title: 加热融化
  do:
    - show: fire # 先放：火出现，温度计还在 -10 ℃
    - ask: true
    - count: { target: th, from: -10, to: 0, duration: 3s } # 答完再放：升温
  try:
    task: 冰加热到几摄氏度，开始融化成水？
    choose: { answer: 0, options: [0, 10, 100] }
```

## 题目说到的画出来，要孩子答的才不画（blank）

提问（有 `try` + `ask`）时，舞台要把**题目里已经说到的东西画出来**，只把**要孩子答的那一个**空着，答对后再填上。例如问“把 6 拆成 1 和几？”：6 下面的分叉、左边的 1 要画出来，右边画成空框，孩子选对 5 才显示 5。拖动题同理：要拖的结果不画，其他照画。

- **拆分算式图**：`blank: [q]`，节点名列表（`a b p q m r`；r 是得数），这些节点不写数字，画成和数字一样大的虚线圆角空框并缓慢闪烁。`set: { target: calc, blank: [] }` 填上。
- **文字**：`[{rest}](blank)` 画成同宽的空框（可以和颜色一起写：`[15](red blank)`），配合 `set: { target: eq, text: ... }` 填上。
- 空框的线宽、虚线、透明度、闪烁周期在 `site.yaml` 的 `scene.blank`；“减少动态效果”时不闪；导出的静止帧里就是空框。
- 看一看、看我做一遍时 `ask` 不起作用：空框会先出现，随后马上填上。

```yaml
- title: 把小数拆开
  do:
    - set: { target: calc, show: 1, blank: [q], duration: 0.8s } # 画出分叉和左边的 {gap}，右边空着
    - ask: true
    - set: { target: calc, blank: [], duration: 0.5s } # 答对了，右边填上
  try:
    task: 把 {b} 拆成 {gap} 和几？
    choose: { answer: '{rest}', min: 1 }
```

检查每个知识点时问自己：题目里说出的每样东西，提问时舞台上都有了吗？

## 文字宽度、底块与高亮框的间距

算式里颜色标记的底块**每一段单独居中画**，所以一定和数字对齐。文字宽度是估算的（导出和测试都不依赖浏览器排版），各类字符的系数在 `site.yaml` 的 `scene.textMetrics`（数字、拉丁字母、空格、运算符、汉字），按最宽的动画主题字体取值，宁宽勿窄。

底块和虚线高亮框的内间距统一配置在 `scene.highlight`：`padX`、`padY` 是高亮框比零件包围盒外扩多少（横向留得多一些，不压到文字边缘），`markPadX`、`markPadY`、`markRadius` 是底块的内间距和圆角（字号的倍数）。所有零件、所有知识点共用，不在每处单独调。

## 手机上贴合内容（fit）

手机（≤767px）上，舞台的画面范围收到“这个动画所有步骤里所有零件包围盒的并集（含高亮框外扩）”再加边距，宽高比也跟着变，动画在窄屏上尽量放大；电脑、iPad 不变。配置在 `site.yaml` 的 `scene.fit`：`phone`（是否启用）、`margin`（边距）、`topPx`（顶部给左上角“时长 · 第几步”留的高度，像素）、`minRatio`（宽高比下限，内容太高时左右补空）。摆零件时不用管它；但**不要把零件摆在舞台很远的地方**（会把范围撑大）。左上角的“时长 · 第几步”会盖住舞台左上角一小块，别把重要内容放在那里。

## 一个一个分（deal）

```yaml
- deal: { target: pool, into: [pl1, pl2, pl3] } # 分一轮：每组放 1 个
- deal: { target: pool, into: [pl1, pl2, pl3], count: 7 } # 一共分 7 个，轮流放
```

从 `target`（一组计数块）的末尾一次拿一个，依次放进 `into` 的各组（轮流），每个飞一段弧线。默认时长 = 每个 0.45 秒（`site.yaml` 的 `scene.actionSeconds.deal`）× 个数。**余数**：个数不够放满最后一轮时，最后一轮分不满，前几组多 1 个，剩下的留在原处，可以讲“还剩几个，不够再分”。

孩子来做时用多目标拖动：`try: { drag: { from: pool, to: [pl1, pl2, pl3], count: 3, each: 1 } }`（`to` 是列表，`each` 是每个目标最多放几个），`do` 里对应的标准做法就是上面的 `deal`（`target` = `from`，`into` = `to`，顺序相同）。

## 重复（repeat）与算式

零件和动作都可以按次数复制，复制出来的每一份里 `{i}` 是第几份（从 1 开始）；`{…}` 里可以写算式，整个值就是 `"{算式}"` 时保留数字类型。不要嵌套。

### 算式支持的运算与函数

- **四则运算**：`+`、`-`、`*`、`/`、`%`（取余）、括号 `()`。
- **比较运算**：`>`、`<`、`>=`、`<=`、`==`、`!=`（结果为 1 或 0，优先级低于加减）。
- **逻辑运算**：`&&`、`||`、`!`（结果为 1 或 0）。
- **条件运算**：`c ? x : y`（最低优先级，右结合，支持短路）。
- **常用数学函数**：`min(...)`、`max(...)`、`floor(x)`、`ceil(x)`、`round(x)`、`abs(x)`。
- **小学数学扩展函数**：
  - `digit(n, k)`：取数字的第 k 位（`floor(abs(n) / 10^k) % 10`；k = 0 个位，k = 1 十位；k 为负时取小数位，如 `digit(3.45, -1)` = 4）。
  - `len(n)`：整数部分位数（`len(0)` = 1，`len(123)` = 3）。
  - `gcd(a, b)`：最大公因数（非负整数；有 0 时 `gcd(a, 0) = a`）。
  - `lcm(a, b)`：最小公倍数（非负整数；有 0 时 `lcm(a, 0) = 0`）。
  - `isPrime(n)`：质数判断（质数得 1，否则得 0；n < 2 为 0）。
  - `dec(n, k)`：四舍五入保留 k 位小数，返回数字（如 `dec(2.345, 2)` = 2.35）。
  - `pow(a, b)`：整数次幂（如 `pow(2, 3)` = 8）。

```yaml
objects: # 每分一轮，右边多一行减法：12 − 3 = 9、9 − 3 = 6……
  - {
      repeat: '{per}',
      id: 'sub{i}',
      type: text,
      text: '{total - 3 * i + 3} − 3 = {total - 3 * i}',
      at: [600, '{50 + 34 * i}'],
      hidden: true,
    }
steps:
  - do:
      - repeat: '{per - 2}'
        do:
          - deal: { target: pool, into: [pl1, pl2, pl3] }
          - show: 'sub{i + 2}'
```

零件内部的列表也可以按出题参数生成（如 `item-set` 的 `items`、`chart` 的 `values`）：
- 列表元素写 `repeat`：按次数展开，元素内的 `{i}` 从 1 开始，次数为 0 的项会被去掉。
- 数值序列用 `'{range(from, to, step)}'`：返回从 `from` 到 `to`、步长为 `step` 的数字列表（包含两端），只能作为整个属性值使用。

```yaml
- id: fruits
  type: item-set
  items:
    - { repeat: '{a}', asset: apple, tags: { kind: apple } }
    - { repeat: '{b}', asset: pear, tags: { kind: pear } }
- id: bars
  type: chart
  kind: bar
  values: '{range(2, 2 * n, 2)}' # n = 4 时为 [2, 4, 6, 8]
```

## 数字格式与文字函数

讲解和零件文字里用 `{参数}` 代入数字时，引擎会自动消除浮点误差（如 `0.1 + 0.2` 显示为 `0.3`），多余的末尾 0 会去掉（`2.50` 显示为 `2.5`），负号统一使用 `−`（U+2212）。

当需要指定小数位数、汉字读法、时间或条件选词时，可以在 `{}` 最外层使用**文字函数**（文字函数之间可以互相嵌套，但不能和算式混在一起运算，如 `{cn(a) + 1}` 会报错）：

| 函数 | 结果 | 例子 |
|---|---|---|
| `fixed(x, k)` | 保留 k 位小数，**保留**末尾 0 | `{fixed(2.5, 2)}` → `2.50` |
| `cn(n)` | 汉字读法（小学读数规则） | `3005` → 三千零五；`40020` → 四万零二十；`100000000` → 一亿；`1.25` → 一点二五；`−5` → 负五；`0` → 零；`10` → 十；`12` → 十二；`110` → 一百一十 |
| `time(m)` | 分钟数 → `h:mm`（超过 1440 取模） | `{time(185)}` → `3:05` |
| `hm(m)` | 分钟数 → `h 时 mm 分`；整点只写 `h 时` | `{hm(185)}` → `3 时 05 分`；`{hm(180)}` → `3 时` |
| `mixed(a, b)` | 假分数 a/b → 带分数标记 | `{mixed(7, 4)}` → `[1 3/4](frac)`；整除时得整数 `{mixed(8,4)}` → `2`；真分数 → `[3/4](frac)` |
| `sel(c, x, y)` | 条件选文字：c 为真（非 0）得 x，否则得 y；x、y 是用引号括起来的文字（单引号或双引号），也可以是另一个文字函数 | `{sel(a > b, '>', sel(a < b, '<', '='))}`；`{sel(carry, '要进位', '不用进位')}` |

```yaml
steps:
  - say: '一共是 {cn(total)} 元，也就是 {fixed(total, 2)} 元。'
  - say: '经过了 {hm(mins)}（{time(mins)}）。'
  - try:
      choose:
        answer: '{sel(a > b, ">", sel(a < b, "<", "="))}'
        options: ['>', '<', '=']
```

## 步骤复制与条件

步骤可以按次数复制，也可以根据条件决定是否出现。在步骤上写 `repeat` 或 `when`：

```yaml
steps:
  - repeat: '{len(a)}'           # a 有几位就复制几步
    title: 第 {i} 位
    say: '{digit(a, i - 1)} 加 {digit(b, i - 1)}……'
    do:
      - set: { target: calc, show: '{i}' }
```

- **`repeat`**：整数或 `'{算式}'`。
  - 按次数复制这一步，每份的作用域中包含 `{i}`（从 1 开始）。
  - 步骤里的 `title`、`say`、`do`、`try` 均可代入 `{i}`。
  - `repeat: 0`（或算式结果 ≤ 0）时，这一步消失。
  - 展开后步数不能为 0，且不能超过 `scene.maxSteps`（`site.yaml` 中配置，默认 20 步）。
- **`when`**：条件算式 `'{算式}'`。
  - 结果为 0 时跳过这一步；结果非 0 时保留。
  - 和 `repeat` 同时写时，每份根据其 `{i}` 单独判断；例如 `repeat: '{len(a)}'` 配 `when: '{digit(a, i - 1) > 0}'` 只保留非零位。
  - 算式写错在 `content:check` 时会报错。

## 多选（choose）

`choose.answer` 写成列表就是多选，`options` 最多 6 个：

```yaml
try:
  task: 种子发芽需要哪几个条件？把它们都选出来。
  choose:
    answer: [水分, 空气, 适宜的温度]
    options: [水分, 阳光, 空气, 土壤, 适宜的温度]
```

选对的留着变绿，选错的弹回并给提示；全部选出才算做对、才进入下一步；停下来超过 `site.yaml` 的 `player.handsOn.remindMs` 提示还差几个。

## 动手做（try）

在某一步加 `try`，这一步在“跟着做”“自己做”时由孩子来做；`do` 仍写标准做法（“看一看”时播放、“看我做一遍”、做对后的画面都用它）。示例见 [math/g1/make-ten.yaml](./math/g1/make-ten.yaml) 第 4 步。

```yaml
try:
  task: 把 {gap} 个橙色圆片拖进十格框。 # 轮到孩子时显示并朗读（不超过约 30 字）
  drag: { from: one, to: left, count: '{gap}' } # 把 from 这组计数块拖 count 个到 to 上
  hints: # 做错时依次给出；不写用通用提示
    - 要放进左边的十格框里哦。
    - 看，放到亮起来的十格框里。
```

| 动手方式 | 写法                                                                                           | 做对的条件                                                                                                             |
| -------- | ---------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `drag`   | `from`（计数块）、`to`（零件，或零件列表）、`count`、`each`（`to` 是列表时每个目标最多放几个） | 拖够 `count` 个到 `to` 上；`do` 里要有把 `from`（或从它拆出来的一组）移动/合并到 `to` 的动作，移过去的个数等于 `count` |

**点选答案（`choose`）**：字幕框里出现几个大按钮，孩子点出答案；所有模板（场景、分数、钟表）都能用。

```yaml
try:
  task: 十格框里还空着几格？
  choose: { answer: '{gap}', min: 1, show: [left] }
  hints:
    - 数一数十格框里空着的格子。
```

| 字段        | 含义                                                                             |
| ----------- | -------------------------------------------------------------------------------- |
| `answer`    | 正确答案，数字或文字，可以写参数，如 `'{gap}'`、`'{take}/{parts}'`               |
| `options`   | 选项（2–6 个）。数字答案可以不写：自动生成“答案和离它最近的两个数”，顺序每次打乱 |
| `min`/`max` | 自动生成选项时数字的范围，如钟面最大是 12                                        |
| `show`      | 做错几次后高亮这些零件或子项（零件 id 或 `id.子项`，支持 `*`）                    |

- 画面停在这一步开头：问的内容要能从那时的画面上看出来；这一步的 `do` 是答案揭晓后放的动画和“看我做一遍”。
- 选项少于 2 个、答案不在选项里、文字选项重复，`content:check` 会按每种参数组合报错。

- 做错几次高亮目标、几次自动演示、放下的容差、按下范围，在 `site.yaml` 的 `player.handsOn` 和 `scene.tryIt`。
- 点选零件（`tap`）、转动/拖动把手（`turn`）随后加。
